## How to run FarmBook

1. Install Java 21 and Maven.
2. In the project folder, run `mvn clean javafx:run`.
3. There is no default account. On the Login screen click Register, make an account (username, email, password), then log in.
4. Your account is saved in `farmbook.db` on your own computer, so each machine needs its own account.

To run the tests: `mvn clean test`.
