# FarmBook usability test

## Who and how
- 3 to 5 people who have never used FarmBook (classmates, family, a farmer if you know one).
- About 10 minutes each. One person runs the test, one watches and writes notes.
- Say this first: "We're testing the app, not you. If something is confusing, that's our mistake. Please think out loud."
- Do not help or hint. If they are stuck for 30 seconds, write down where and move on.
- Record people as P1, P2, P3. No names.

## Tasks (read each one out loud, one at a time)
1. Create an account and log in.
2. Add an animal: a cow, tag #A12, born on 3 February 2025.
3. Find the list of animals, then get back to the home page.
4. Open Inventory, add an item, then get back to the dashboard.

## Questions afterwards
1. What was the most confusing part?
2. Was anything hard to find?
3. Did any error message make sense? (Ask them to type a bad date like 2025-13-45 and read the message.)
4. One thing you would change?

## Limits of this test
- Only a few people, mostly students, not farmers.
- We watched them use a laptop. Farmers may use it outdoors or on other devices.
- We did not test accessibility, such as screen readers or colour blindness.
