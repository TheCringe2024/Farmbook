\# Version Control Evidence



\## Workflow



FarmBook uses Git and GitHub with `main` as the shared integration branch.



Feature, fix, testing and documentation work is developed on separate branches and integrated into `main` through pull requests and merges.



\## Evidence Files



\- `commit-history.txt` — recent repository commits with hash, date, author and commit message.

\- `branches.txt` — local and remote branch history.

\- `merge-history.txt` — merge commits showing integration of development work into shared branches.

\- `contributors.txt` — contribution summary by author.



\## Iterative Development



The repository history shows that features were developed incrementally rather than as a single final implementation.



For example, the Livestock feature progressed through separate changes for validation, navigation, persistence verification, save feedback and Week 9 documentation.



This supports the project’s Agile workflow by linking implementation changes to evolving user stories and prototype requirements.
